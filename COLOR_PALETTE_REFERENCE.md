## 🎨 CSS Variables (For Switching Themes)

### To Use Old Theme, Add This to style.css:

```css
:root {
  /* Old Theme Colors */
  --primary: #FF0000;
  --primary-dark: #CC0000;
  --primary-glow: rgba(255, 0, 0, 0.3);
  
  --background: #111111;
  --card: #181818;
  --border: #2a2a2a;
  
  --text: #F7F7F7;
  --text-muted: #C8C8C8;
  
  --accent: #FFD700;
  --highlight: #3ebbff;
  --highlight-bright: #5ecfff;
}
```

### To Use Current Theme, Add This to style.css:

```css
:root {
  /* Current Theme Colors */
  --primary: #39b54a;
  --primary-dark: #2e8e3b;
  --primary-light: #39b54a;
  
  --background: #f5f5f5;
  --card: #ffffff;
  --border: #ddd;
  
  --text: #1a1a1a;
  --text-secondary: #333;
  --text-muted: #999;
  
  --accent: #ffd700;
  --accent-light: #ffed4e;
  
  --purple: #a855f7;
  --purple-dark: #9333ea;
  
  --link: #0066cc;
  --link-hover: #5ecfff;
}
```

### Current Theme (Light Mode)
- **Contrast Ratio Text**: 7.8:1 (AAA) ✅

### Old Theme (Dark Mode)
- **Contrast Ratio Text**: 7.5:1 (AAA) ✅

- **Suitable For**: Low light environments, reduced glare
